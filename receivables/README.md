# 混凝土应收账款催收管理

一个**单文件、免安装、免登录**的应收账款催收管理工具，专为混凝土等有大量应收账款、需要轮动催收的企业设计。

## 使用方法

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。无需联网、无需服务器。

> 数据只保存在本机浏览器（localStorage），不会上传到任何服务器。

## 功能

- **应收台账**：记录客户、工程/项目、合同号、混凝土标号、方量、单价、合同总额、已收/未收金额、账期与约定付款日期。
- **自动预警**（无需手动判断）：
  - 🔴 **已逾期**：超过约定付款日仍未结清 → 紧急催款
  - 🟠 **临近到期**：距约定付款日在设定天数内（默认 7 天）
  - 🟠 **久未跟进**：距上次催收超过设定天数（默认 15 天）且仍有欠款
  - 🟢 **正常** / ⚪ **已结清**
- **今日催收清单**：把所有需要催的账款按优先级排好，逐条打电话、记录答复、约定下次跟进时间，实现"轮动催收"。
- **每日对账导入**：把群里每天发的欠款明细（微信长按截图→「提取文字」→复制粘贴）贴进来，自动比对台账：欠款增加记为新供货、减少记为回款、新客户自动建档、表中未出现的欠款客户给出核对提醒。支持"名称+金额同行"和"名称、金额分两行"两种格式，表头/日期/合计行自动跳过。
- **催收记录**：每笔账款可记录多次催收的时间、方式、对方答复、下次跟进日期。
- **金额自动核算**：方量 × 单价自动算合同总额；发货日 + 账期自动算到期日；未收余额自动计算。
- **统计看板**：应收总额、逾期金额、待跟进笔数、已结清笔数，点击卡片快速筛选。
- **导入 / 导出**：JSON 备份（可再导入）、CSV 表格（Excel 可打开）。

## 预警规则设置

点击右上角「⚙️ 预警设置」可调整"临近到期"提前天数和"久未跟进"天数。

## 数据备份提醒

数据存于浏览器本地，**清理浏览器缓存会导致数据丢失**。请定期点击「导出」保存 JSON 备份文件到电脑。

## 首次打开

首次打开会自带几条示例数据以便预览。可在「⚙️ 预警设置」中「清空全部数据」后录入自己的真实数据。
