# 混凝土应收账款 · 合同对账催收管理

一个**单文件、免安装、免登录**的应收账款管理工具，专为混凝土等应收账款多、且**回款卡在合同/对账单没走完**的企业设计。

## 使用方法

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。无需联网、无需服务器。

> 数据只保存在本机浏览器（localStorage），不会上传到任何服务器。

## 设计出发点

真实催收里，钱要不回来，多数不是"客户不给"，而是**单据没走完**：无合同、无对账单、对账单没签字、对账单没归、金额/单价还没确认。所以本工具不只做"逾期催款"，而是把**合同 → 对账 → 对账单 → 金额确认 → 催款**整条链路的卡点都管起来。

## 功能

- **项目台账**：客户/单位、工程项目、业务对接人、供货周期、混凝土标号、方量/单价/合同总额、已收/欠款。
- **合同 / 对账 / 单据状态**：每个项目单独记录
  - 合同状态：已归档 / 合同未归 / 无合同 / 需补充合同（超方）
  - 对账状态：已对账 / 部分对账 / 未对账
  - 对账单状态：已归档 / 对账单未归 / 对账单未签 / 已签存疑 / 无对账单
  - 金额是否已确认（未定价、易货、暂按开票入账等 → 标记"待确认"）
- **待办清单（卡点自动排序）**：系统按优先级算出每个项目"下一步该干嘛"——
  待确认金额 → 逾期催款 → 待对账 → 催对账单签字/回收 → 签/催合同 → 待收款，一目了然。
- **统计看板**：应收欠款合计、待确认金额、单据待办、逾期催款、已完结；点卡片直接筛选。
- **催收 / 跟进记录**：每个项目可记录多次跟进的时间、方式、对方答复、下次跟进日期。
- **每日对账导入**：把群里每天发的欠款明细（微信长按截图→「提取文字」→复制粘贴）贴进来，自动比对台账：欠款增加记为新供货、减少记为回款、新客户自动建档、表中未出现的欠款客户给出核对提醒。
- **金额自动核算**：方量 × 单价自动算合同总额；发货日 + 账期自动算到期日；欠款自动计算。
- **导入 / 导出**：JSON 备份（可再导入）、CSV 表格（Excel 可打开，含全部状态与"下一步待办"列）。

## 预警规则设置

点击右上角「⚙️ 设置」可调整"临近到期"提前天数和"久未跟进"天数。逾期规则固定：超过约定付款日仍未结清 → 红色紧急催款。

## 完结判定

一个项目算"已完结"，需同时满足：钱已收清 + 金额已确认 + 无合同/对账/对账单卡点。

## 数据备份提醒

数据存于浏览器本地，**清理浏览器缓存会导致数据丢失**。请定期点击「导出」保存 JSON 备份文件到电脑。

## 首次打开

首次打开会预置一批来自《各项目合同、对账情况梳理》的真实项目数据以便直接上手。可在「⚙️ 设置」中「清空全部数据」后录入/导入自己的数据。
