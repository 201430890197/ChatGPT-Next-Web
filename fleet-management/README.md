# 混凝土企业车队管理系统

面向混凝土企业的**车队管理单页应用**，自包含单个 `index.html`，双击即可在浏览器打开使用，无需服务器、无需安装。所有数据保存在浏览器本地（localStorage）。

## 功能模块

### 📊 数据看板
- 车辆总数、运营中 / 维保 / 停用统计
- 今日运输任务与方量汇总
- **证件 / 保养到期预警**（行驶证、保险、年检、驾照、从业资格证、下次保养——30 天内或已逾期自动提醒）
- 车队健康度：完好率、卫生平均分、司机安全平均分
- 车辆分类统计、待处理安全隐患

### 🚛 车队管理（核心）
- **车辆台账**：车牌、类型（搅拌车 / 泵车 / 自卸车 / 罐车…）、型号、方量载重、里程、证件到期、状态
- **司机档案**：证件到期、绑定车辆、安全评分
- **运输任务 / 派车**：工程项目、混凝土标号（C15–C60）、方量、出发送达、状态跟踪
- **维保保养**：保养 / 维修 / 年检记录、费用、下次保养提醒
- **里程油耗**：加油记录，自动计算百公里油耗

### 🚿 车队卫生
- **清洗记录**：罐体冲洗、车身清洗、残料清理、评分
- **卫生检查**：车容车貌、罐体清洁、防遗撒 / 环保、综合评分与整改

### 🛡️ 车队安全
- **安全检查**：出车前检查表（制动 / 轮胎 / 灯光 / 灭火器 / GPS…）
- **隐患排查**：隐患登记、等级、责任人、整改闭环
- **事故 / 违章**：台账、扣分罚款、责任认定、处理状态
- **安全培训**：安全教育与考核记录

## 使用方法

1. 直接用浏览器打开 `index.html`
2. 首次打开自带演示数据，可直接体验；点击各模块「新增 / 编辑 / 删除」维护数据
3. 侧边栏底部支持数据 **导出 / 导入（JSON）/ 重置**，便于备份与迁移

## 技术说明
- 纯前端，零依赖，单文件；数据驱动的通用增删改查引擎，新增业务模块只需在 `schemas` 中增加一段表结构定义。
- 数据存于浏览器 `localStorage`，清除浏览器数据会丢失，请定期使用「导出」备份。
