# 原材料进销存（混凝土搅拌站）

一个**单文件、纯前端**的原材料进销存工具，口径贴合搅拌站的《生产消耗、原材料汇总表》日报。所有数据保存在浏览器本地（localStorage），**无需联网、无需服务器、无需安装**。

## 打开方式

- 直接双击 `public/inventory/index.html` 用浏览器打开即可；
- 或部署本仓库后访问 `/inventory/`（Next.js 会把 `public/` 作为静态资源提供）。

建议用 Chrome / Edge / 手机浏览器。数据只存在当前这台设备的这个浏览器里，请定期用「导出备份」保存 JSON。

## 核心思路：用「电脑消耗」抓跑冒滴漏

搅拌站发现材料损耗，靠的是**理论应耗**与**实际消耗**两条线的对比：

```
理论应耗 = 配料主机记录的「电脑消耗」（该出多少料）
实际消耗 = 期初库存 + 进厂 − 期末实盘          （实际少了多少料）
损  耗  = 实际消耗 − 电脑消耗
损 耗 率 = 损耗 / 电脑消耗 × 100%
```

- **损耗为正（超耗）**：实际比理论多耗 → 疑似过磅作弊、皮带/装载撒漏、雨天砂含水虚增、配料机计量偏差、盗料。
- **损耗为负（偏少）**：可能进厂虚报、配比给料不足或盘点误差。
- 损耗率超过该材料的**阈值**即标红预警（各材料正常损耗不同，可在「材料设置」调）。
- **账面倒挂预警**：账面库存（期初＋进厂−电脑消耗）为负时直接报警——这通常意味着进厂漏记或电脑消耗虚高，就是你们现在表里那些带括号的负库存。

> ⚠ 实际消耗依赖**盘点数据**。没有盘点就只有账面数，发现不了真实损耗——所以要定期（如每月末）盘点一次。
> 期初取区间开始前最近一次盘点（无则取材料设置里的期初）；期末取区间内最近一次盘点，盘点后即成为后续账面的新基准。

## 功能模块

| 模块 | 说明 |
|------|------|
| 📊 总览 | 各材料实时账面库存、账面倒挂/低库存告警、累计快照 |
| 📝 生产日报 | 按天录入各材料「电脑消耗」+「进厂」（吨）；账面自动滚动结转；含生产/销售方量 |
| 📋 库存盘点 | 录入实盘库存，与账面自动对比盈亏 |
| 🔍 损耗分析 | **核心**：电脑消耗 vs 实际消耗，损耗率＋阈值预警 |
| ⚙️ 材料设置 | 材料大类、期初/安全库存、损耗阈值、导入别名 |

材料按**大类**管理（水泥、矿粉、粉煤灰、膨胀剂、石粉、机制砂、细砂、碎石、卵石、外加剂、早强剂、柴油、尿素），各仓/各线合并统计。用不到的大类可在「材料设置」删除。

## 粘贴导入日报表

「生产日报 → 📥 从粘贴表格填充」：把材料统计员发的日报表（Excel/Word 表格）整段复制粘贴进去，系统会：

1. 自动识别「电脑消耗」「进厂」两行；
2. 把原始列名（如 `1线水泥`、`聚羧酸`、`0-5籽`、各仓/各线）按**别名**归到大类，`kg` 自动换算成吨；
3. **先显示预览、可逐项手动修改**，确认无误后再写入当日日报。

> 表格合并单元格千差万别，自动解析可能有偏差，所以一律**先预览再保存**。若某列没归对，到「材料设置」给对应大类补个别名即可。

## 数据安全

- 数据仅存于本地浏览器，清缓存/换设备会丢失，请常用「导出备份」保存 JSON。
- 换电脑时用「恢复备份」导入。
- 日报支持导出 CSV，可用 Excel 打开。

## 快速上手

点右上角「示例数据」载入一套演示（20 天日报 + 期末盘点），其中**机制砂**被故意设为超耗约 10%（模拟跑冒滴漏），到「损耗分析」即可看到只有机制砂标红预警。用熟后到「材料设置 → 清空全部数据」重新开始录入真实数据。
