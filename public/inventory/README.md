# 原材料进销存（混凝土搅拌站）

一个**单文件、纯前端**的原材料进销存工具，面向混凝土搅拌站，管理 **砂、石、水泥、粉煤灰、外加剂** 的进货、消耗与损耗。所有数据保存在浏览器本地（localStorage），**无需联网、无需服务器、无需安装**。

## 打开方式

- 直接双击 `public/inventory/index.html` 用浏览器打开即可；
- 或部署本仓库后访问 `/inventory/`（Next.js 会把 `public/` 作为静态资源提供）。

建议用 Chrome / Edge / 手机浏览器。数据只存在当前这台设备的这个浏览器里，请定期用「导出备份」保存 JSON。

## 功能

| 模块 | 说明 |
|------|------|
| 📊 总览 | 各材料实时账面库存、安全库存告警、经营快照 |
| 🚚 进货过磅 | 记录毛重/皮重/净重、供应商、车号、单价金额；净重自动累加入库 |
| ⚗️ 配比管理 | 维护每个标号（如 C30）每方 kg/m³ 的理论用量 |
| 🏭 生产领用 | 按「配比 × 生产方量」自动计算理论消耗并扣库存 |
| 📋 库存盘点 | 录入实盘库存，与账面自动对比盈亏 |
| 🔍 损耗分析 | **核心**：理论用量 vs 实际消耗，自动预警异常损耗 |
| ⚙️ 材料设置 | 期初库存、安全库存、每种材料的损耗率预警阈值 |

## 损耗分析口径（核心）

发现「跑冒滴漏」靠的是**理论**与**实际**两条线的对比：

```
理论消耗 = Σ(配比 kg/m³ × 生产方量 m³) / 1000        —— 生产该出多少料
实际消耗 = 期初库存 + 区间进货 − 期末实盘             —— 实际少了多少料
损  耗  = 实际消耗 − 理论消耗
损 耗 率 = 损耗 / 理论消耗 × 100%
```

- **损耗为正（超耗）**：实际比理论多耗 → 疑似过磅作弊、皮带/装载撒漏、雨天砂含水虚增、配料机计量偏差、盗料。
- **损耗为负（偏少）**：可能进货虚报、配比给料不足或盘点误差。
- 损耗率超过该材料设定的**阈值**即标红预警（各材料正常损耗不同，默认：砂 3%、石 2.5%、水泥/粉煤灰/外加剂 1.5%–2%）。

> ⚠ 实际消耗依赖**盘点数据**。没有盘点就只有账面数，无法发现真实损耗——所以要定期（如每月末）盘点一次。

期初取区间开始前最近一次盘点（无则取材料设置里的期初）；期末取区间内最近一次盘点。

## 数据安全

- 数据仅存于本地浏览器，清缓存/换设备会丢失，请常用「导出备份」保存 JSON 文件。
- 换电脑时用「导入」恢复备份。
- 进货、生产记录支持导出 CSV，可用 Excel 打开。

## 快速上手

点右上角「示例数据」载入一套演示数据，其中**砂**被故意设为超耗（模拟跑冒滴漏），到「损耗分析」即可看到预警效果。用熟后到「材料设置」→「清空全部数据」重新开始录入自己的真实数据。
